## SmartBookHub - 前端
 
### 项目介绍
 
智能知识库前台项目，基于 Vue3 + Vite + TypeScript 开发，实现文章浏览、发布、评论、收藏、AI对话、个人中心、管理员后台审核等完整页面与交互功能。
 
### 技术栈
 
- Vue3 + Composition API
- TypeScript
- Vite
- Element Plus
- Pinia 状态管理
- Vue Router
- Axios 请求封装
- ECharts 数据可视化
- WangEditor 富文本编辑器
 
### 主要功能
 
- 首页文章浏览、分类、搜索、筛选
- 文章发布、编辑、草稿保存、封面上传
- 多级评论、回复、点赞功能
- AI 流式智能对话、会话管理
- 个人中心：资料修改、头像更换、我的收藏
- 管理员后台：文章审核、数据统计、用户管理
 
### 项目启动
 
```bash
  npm install
  npm run dev
```
### 环境变量配置 
- 将  .env.example  复制为  .env ，配置后端接口地址、图片资源地址等环境参数。
